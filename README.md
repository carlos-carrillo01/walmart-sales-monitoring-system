# Sistema de Monitoreo y Análisis de Ventas

Proyecto académico para la materia de Ingeniería de Software.

## Objetivo
Desarrollar un sistema que permita el monitoreo y análisis de ventas de una sucursal Walmart,
incluyendo visualización, reportes y análisis de datos históricos.

## Tecnologías
- Backend: FastAPI
- Frontend: Vue 3
- Base de Datos: PostgreSQL
- Infraestructura: Docker

## Alcance
El sistema implementa un conjunto priorizado de requerimientos funcionales y no funcionales,
documentados en la carpeta /docs.
